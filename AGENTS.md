# Preferências do projeto

- Preferência registrada em 14/09/2026: usar React como base padrão para interfaces, componentes visuais e trabalhos de design. Seguir os componentes React existentes em `resources/js` e a integração com Inertia/Laravel.
- Neste contexto, “fonte padrão é React” significa a tecnologia base da interface, não uma família tipográfica.
